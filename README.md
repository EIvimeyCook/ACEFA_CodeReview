This is the repository of the dedicated website for the **ACEFA Forecasting Model
Code Review** — a Shiny app that guides reviewers through a structured assessment
of an ACEFA epidemiological forecasting model code base and produces a HTML
report to return to its authors.

This app gives every reviewer the same five questions in the same
order, on the same response scales, so reports are consistent and the authors can
see where opinion converges. It is compiled to WebAssembly with
[shinylive](https://posit-dev.github.io/r-shinylive/), so reviewers need no R
installation and no server access.

## Features

- **Five paired steps.** Each practical instruction is followed by the criterion
  it supports, so reviewers assess what they have just done.
- **Response scales suited to the question.** Judgement calls use a 1–5 scale;
  the reproducibility check is Yes/No; two steps offer *Unable to assess* rather
  than forcing a score.
- **A comment box on every criterion.** The scores tell authors roughly where they
  stand; the comments tell them what to do.
- **Self-contained HTML report** that opens in a new tab with a one-click
  download.
- **Runs entirely in the browser.** No installation, no server.

## Usage

Open the deployed site. First load takes a moment while the browser downloads the
R runtime; later visits are cached.

1. Enter the code base under review and your name.
2. Work through the five steps, with the shared materials open alongside.
3. Click **View HTML Report**, then download it from the button at the top.
